# BOJ 2133번 타일 채우기

## 문제 요약
3×N 크기의 벽을 2×1, 1×2 크기의 타일로 채우는 경우의 수를 구하면 된다.

++) N은 1이상 30이하의 자연수이다.

## Naive한 접근
이전의 3xN 타일을 채우는 경우의 수에 타일을 추가하여 다음 3xN 타일을 채울 수 있으므로 DP로 접근하여 점화식을 세운다. 이때 N이 홀수일 때는 타일 전체를 채울 수 없으므로
dp[i]의 i가 홀수이면 모두 0으로 채운다.

## Attempts
## Attempt 1 - Flawed_Logic
dp[i]는 dp[i-2]로부터 채울 수 있는 경우가 세가지 존재하므로 dp[i] += dp[i-2]*3 이라는 점화식을 세웠고 이 방식으로 세지 못하는 패턴을 찾아 예외 추가 해주었으나 규칙을
잘못 인식하여 WA를 받았다.

## Attempt 2 - Accepted Solution
Attempt 1에서 셌던 dp[i] += dp[i-2]*3를 포함하여 i가 2 증가함에 따라 새로운 패턴이 2개씩 추가된다는 것을 인지하고 반복문을 통해 2씩 증가하는 j에 대해 dp[i] += dp[i-j]*2로 점화식을 세워 AC를 받았다.

## 구현 포인트
최소 dp[i-4]를 활용하므로 직접 세기 쉬운 dp 테이블의 인덱스 0~3 부분까지는 저장해두었고 이후 이 값들을 활용하여 점화식으로 구한 값을 append하는 방식으로 구현하였다.

# BOJ 17472번 다리 만들기 2

## 문제 요약
NxM 크기의 격자 정보에서 0은 바다 1은 섬을 의미한다. 1이 상하좌우에 인접해 있으면 그것은 하나의 섬으로 본다. 다리를 연결해서 모든 섬을 연결하려고 한다. 다리의 길이는 다리가 격자에서 차지하는 칸의 수이다.  섬 A에서 다리를 통해 섬 B로 갈 수 있을 때, 섬 A와 B를 연결되었다고 한다. 다리의 양 끝은 섬과 인접한 바다 위에 있어야 하고, 한 다리의 방향이 중간에 바뀌면 안된다. 또, 다리의 길이는 2 이상이어야 한다. 섬 A와 B를 연결하는 다리가 중간에 섬 C와 인접한 바다를 지나가는 경우에 섬 C는 A, B와 연결되어있는 것이 아니다. 교차하는 다리의 길이를 계산할 때는 각 칸이 각 다리의 길이에 모두 포함되어야 한다. 모든 섬을 연결하는 다리 길이의 최소값을 구해야한다.

++) N과 M은 10보다 작거나 같은 자연수, NxM은 3보다 크거나 같고 100 보다 작거나 같은 자연수, 섬의 개수는 2개 이상 6개 이하이다. 모든 섬을 연결할 수 없으면 -1을 출력한다.

## 핵심 접근
섬을 노드, 섬과 섬 사이를 연결하는 다리를 간선으로 생각하여 섬과 섬 사이의 최소 거리를 모두 기록한 후 크루스칼 알고리즘으로 해결한다. 

## Attempts
## Attempt 1 - Flawed Logic
크루스칼 알고리즘을 수행하고 모든 섬을 연결할 수 있는지 여부를 연결한 다리의 길이가 0인지 아닌지로 판단하였다. 그러나 이 방식으로 판단할 경우 다리를 1개 이상, 노드의 개수-1 보다 더 적게 연결했을 때에도 모든 섬을 연결했다고 판단하여 이는 적합한 판단 기준이 되지 못했고 WA를 받았다.

## Attempt 3 - Accepted Solution
Attempt 1에서의 판단 방법을 수정하여서 AC를 받았다. BFS로 돌면서 섬에게 번호를 부여하고 각 섬의 테두리에서 상하좌우로 쭉 뻗어나가며 다른 섬에 닿았을 때의 거리를 측정하여 섬 사이의 다리의 길이를 기록하였다. 이후 크루스칼 알고리즘으로 모든 섬을 연결하는 다리 길이의 최소값을 구했다.

## 구현 포인트
크루스칼 알고리즘을 효율적으로 수행하기 위해 섬과 다리의 관계를 방향 그래프로 표현한다. 만약 3번 섬에서 2번 섬으로 연결할 경우 (2,3, 다리 길이)로 간선 정보를 노드 기준 오름차순으로 저장하는 것이다.
